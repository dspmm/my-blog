# 代码交付与自动化 CI/CD 规范

## 规则定义
在本项目中完成任何功能开发、样式调优或 Bug 修复后，只需在本地完成代码修改、验证、提交并推送到远端 Git 仓库。云端已配置 Gitea Actions 自动化流水线，代码推送后会自动触发容器重构与上线部署。

## 核心要求
1. **自动触发部署**：
   - 依赖 `.gitea/workflows/deploy.yaml` 自动化部署流程，推送 `main` 分支即触发全自动发布。
2. **禁止调用 SSH MCP 冗余部署**：
   - 代码提交并推送后直接向用户汇报交付，**严禁主动调用 SSH MCP (`linux-server` / `ssh_exec`) 去远程服务器手动执行 `git pull`、`docker compose build` 等重复操作**。
3. **SSH MCP 限制使用场景**：
   - 仅限用户明确提出要求（如“查看云端日志”、“排查服务器故障”、“操作线上数据库”）时方可调用 SSH 相关工具。
